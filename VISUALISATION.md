# Visualización
## 5.1  Graficar trayectorias
Usar Matplotlib para generar:
- Gráfica 3D de trayectoria.
- Comparación entre trayectoria real y estimada.
- Comparación entre configuraciones.

Cada gráfica debe incluir:
- Título
- Etiquetas de ejes.
- Leyenda
- Escala interpretable.
- Nombre del dataset y configuración usada.
## 5.2  Visualizar correspondencias
Usar la función de OpenCV cv2.drawMatches para mostrar las correspondencias de puntos
encontradas en las imágenes consecutivas.
