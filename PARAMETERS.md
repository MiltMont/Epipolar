# Ajuste de parámetros
## 6.1  Reducir errores
Después de obtener resultados iniciales, ajustar parámetros para reducir el error absoluto y
relativo y el tiempo de ejecución. Se deben documentar los cambios realizados, por ejemplo:
Aumentar o disminuir número de matches.
Modificar el umbral de RANSAC.
Cambiar ORB por SIFT.
Modificar la tolerancia de ICP.
Cambiar el número máximo de iteraciones.
Usar la estimación epipolar como inicialización de ICP.
Cada ajuste debe tener una explicación.
