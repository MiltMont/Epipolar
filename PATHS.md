# Evaluación de trayectorias

## 4.1  Error absoluto de trayectoria

El error absoluto de trayectorio campara la trayectoria estimada contra la trayectoria real. Si $p_i$ es la posición estimada y $p_i^*$ es la posición real sociada, el error por instante puede calcularse como:
$$
e_i = \| p_i - p_i^* \|_2
$$

se deben reportar:

- error medio
- mediana
- desviación estándar
- error máximo
- RMSE

## 4.2  Error relativo de trayectoria

El error relativo mide qué tan bien se estiman los desplazamientos entre instantes.
